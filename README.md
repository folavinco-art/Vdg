# China Industry Monitor

A small, self-contained dashboard for collecting and comparing China industry indicators. Open `index.html` in a modern browser—no build step or external dependencies required.

## Features

- Track sector and region, output growth, investment (CNY billion), employment change, signal, reporting period, source, and notes.
- Search and filter records by region and signal.
- Add and edit updates; data is saved in browser `localStorage`.
- Export the current dataset as JSON.
- Summary metrics and a recent-update list.

## Data note

The initial rows are **illustrative demo values**, not current official statistics. The app does not retrieve, validate, or independently collate live data. Replace demo entries with sourced figures and record the publisher, publication date, and reporting period. Data remains in the current browser unless exported.

## Run

Open `index.html` directly, or serve this directory with any static web server.
